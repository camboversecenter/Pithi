# Partner & incubator logos

Drop the logos here named:

- `num`        -> National University of Management
- `e-khmer`    -> e-Khmer
- `camboverse` -> CamboVerse (incubator)

Extension may be **.png**, **.jpg**, **.jpeg**, **.svg** or **.webp** (each is
tried in turn). PNG or SVG with a transparent background looks best.
A placeholder icon shows until a file is added.

Examples: `num.png`, `camboverse.svg`

Note: `ABOUT.md` on GitHub cannot try multiple extensions - it points at
`.png`, so update the paths there if you upload another format.
